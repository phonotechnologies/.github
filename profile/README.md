### [envaudit](https://github.com/phonotechnologies/envaudit) — .env Drift Detector
Rust CLI to detect missing variables across environments and catch accidentally committed secrets.

```bash
cargo install envaudit

envaudit scan       # compare .env files across environments
envaudit check      # validate .env against .env.example (CI-friendly)
envaudit secrets    # detect high-entropy values and known secret patterns
```
